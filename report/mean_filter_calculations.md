# 3×3 Mean Filter – Hand Calculations

A 3×3 Mean Filter replaces each pixel with the average of the nine pixel values in its 3×3 neighborhood.

## 1. Centre Pixel Calculation

Sum of the nine pixel values = 450.

Mean = 450 / 9 = 50.

**Result: Centre Pixel = 50**

## 2. Corner Pixel Calculation

Sum of the nine pixel values = 120.

Mean = 120 / 9 ≈ 13.33.

**Result: Corner Pixel ≈ 13.33**

## 3. Conclusion

The 3×3 Mean Filter smooths an image by replacing each pixel with the average intensity of its neighborhood. This reduces local intensity variations and helps suppress noise.
