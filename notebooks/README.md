# Notebooks

Notebooks are only for image analysis and for presenting results. They import from `src/`
and contain no pipeline logic.

- `01_image_analysis.ipynb` (Week 10) — sizes, dtypes, histograms, illumination, centred
  log-magnitude spectrum, resolution and gray-level reduction study, findings → decisions.
- `02_results.ipynb` (Week 13) — final tables and figures.
